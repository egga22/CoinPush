We are developing an exciting coin-pusher game for android.
This repo contains all the source code, and an APK file that can be directly installed on modern android devices.
I will be the primary user of this app, so optimize for a Google Pixel 8 since that's my phone, making sure it still works fine on all phones.
The goal of the game will be to closely emulate actual modern arcade coin-pushers.
It should be theme-less.
You will have a lot of control over this project, as it's "agent first", and I will serve the role of a project manager, or a client.
Don't be afraid to ask questions, I'd much rather take an extra minute clarifying something then waste hours due to a misunderstanding.
The game should feature no ads or other forms of monetization, feature no external API calls, and work fully offline.
Once you finish reading this, please inform the user of all questions you have, to personalize the app to their liking. Then, generate multiple design ideas, and let the user choose their favorite. Finally, begin programming the app acording the the specifications.
Most choices that don't affect the end user experience, like frameworks used, programming language, etc, can be selected by the agent without human intervention.
